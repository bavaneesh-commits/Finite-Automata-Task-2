# Assignment 2 – Finite Automata for Real-Time Applications

This repository contains a Google Colab/Jupyter notebook demonstrating finite-automata-based validation for:

1. Password verification
2. Email format validation
3. ATM PIN verification

## Run
Open `Assignment_2_Finite_Automata.ipynb` in Google Colab or Jupyter and run all cells from top to bottom.

## Scope
The notebook demonstrates simplified format validation. It does not authenticate users, verify that an email mailbox exists, or implement account/PIN business rules.
